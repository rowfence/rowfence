# AZ110: A dollar-quote tag in a condition

The SQL in `{...}` goes into generated functions, whose bodies are quoted with tags such as `$f$`. The same tag in a condition would end the body there. Write the text another way: `'$' || 'f$'` (`$$` is fine).

Reported when the policy is compiled: `rowfence check`, the editor, `rowfence dev`.

## The mistake

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can view = owner and {name <> '$f$'}
```

```
line 5: {name <> '$f$'} contains $f$, which ends the generated function it goes in: write the text another way ('$' || 'f$') [AZ110]
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can view = owner and {name <> '$' || 'f$'}
```
