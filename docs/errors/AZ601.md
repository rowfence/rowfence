# AZ601: A table or column that isn't there

Applying checks the policy against the database first: each table a type or relation names, and each column a relation reads. Nothing is applied until they are all there. Run the app's schema migrations first, or fix the name.

Reported when the policy is applied (`rowfence push`, `apply`, a migration), against the database.

## The mistake

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_uid
  can view = owner
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can view = owner
```
