# AZ708: No such thing

The call names something that isn't there: the subject to share with, an active user to view as, a pending request, an item of a review, an API key of yours, a link on the object. Answer 404.

Reported to the app, by the `authz.*` functions and the policy's rules: the code is in the error's HINT (`rowstile help AZ708`), and the SDKs' errors carry it as `code`.
