# AZ201: Unknown type

A relation's subjects, an invariant, a scope and a test name types the policy declares (`type team = app.teams`). Declare it, or fix the name.

Reported when the policy is compiled: `rowstile check`, the editor, `rowstile dev`.

## The mistake

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : person = owner_id
  can view = owner
```

```
line 4: folder.owner: unknown type 'person' [AZ201]
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can view = owner
```
