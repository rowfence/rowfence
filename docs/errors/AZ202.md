# AZ202: No user type

Every policy declares `type user = schema.table`: the people who sign in, whose ids `authz.act_as('user', id)` takes.

Reported when the policy is compiled: `rowstile check`, the editor, `rowstile dev`.

## The mistake

```authz
app role app_user
type folder = app.folders
  can view = signed_in
```

```
line 1: declare the user type, e.g.: type user = app.users [AZ202]
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  can view = signed_in
```
